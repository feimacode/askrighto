# Reading published home loan data

Plain meanings, for explaining a result to the user. These describe how the data is published, not what is best.

- **Published rate:** the interest rate a lender lists for a product in its Consumer Data Right data. It may not be the rate a person is offered.
- **Variable and fixed:** a variable rate can change; a fixed rate is set for a stated term, and the result gives the term. What happens when it ends is not covered by these tools.
- **LVR (loan to value ratio):** the loan as a percentage of the property value. Some lenders publish different rates for different LVR bands. Use the figure the user gives.
- **Comparison rate:** a figure some lenders publish to include some fees, true only for the lender's own example. Quote it only as returned.
- **Negotiated (tailored) product:** the lender says its prices are negotiated, so the published figure is not a quote.
- **Offset and redraw:** features a lender lists. An offset account can reduce the interest charged; the calculator shows an illustrative effect for a balance the user states.
- **Fees:** upfront, ongoing and exit fees as published. They are shown beside results, never added into a repayment.
