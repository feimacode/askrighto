# NSW: HSC and UAC

Unconfirmed structure facts (see README). Read the official page for anything specific.

- **Certificate:** the Higher School Certificate (HSC), run by NESA. Courses come at different levels (for example standard and advanced versions, and extension courses), counted in units.
- **Admissions centre:** UAC takes applications, runs preferences and offers, and calculates the ATAR.
- **Figures you may meet:** the ATAR, and a university's selection rank (an ATAR plus any adjustment). Universities say which they publish and for which intake year.
- **Prerequisites and assumed knowledge:** universities use both words. A prerequisite is required; assumed knowledge is expected but not required. Read which word the page uses and say which.
- **Adjustments:** UAC and the universities list schemes that add to a selection rank or consider disadvantage. Names and rules change; read the page.
- **Traps:** a course name can exist at more than one level; the page may name the level. A selection rank is not an ATAR.
