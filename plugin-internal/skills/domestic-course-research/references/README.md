# State notes

One file per admissions system: `vce.md`, `hsc.md`, `act.md`, `qce.md`. They hold structure facts only (what things are called, who publishes what, what to watch for). They hold no score, date or rule; those are read from the official page each time.

**Status: partly confirmed.** These notes were written in November from general knowledge. A device session then read the VTAC, UAC, QTAC and ACT Board pages and found them consistent apart from the lines now corrected; NESA and QCAA were not read (QCAA showed a bot check). A person opens each page and confirms or corrects each note before the notes are relied on (`openspec/changes/generalise-admissions-sources`, task 1). Where a note and the page disagree, the page wins, and the agent says what the page says.
