# Queensland: QCE and QTAC

Unconfirmed structure facts (see README). Read the official page for anything specific.

- **Certificate:** the Queensland Certificate of Education (QCE), run by the QCAA. Subjects come in kinds (the page says which kinds count towards the ATAR).
- **Admissions centre:** QTAC takes applications, runs preferences and offers, and calculates the ATAR.
- **Figures you may meet:** the ATAR and a university's selection rank. Read the label and the intake year.
- **Prerequisites:** usually a named subject, sometimes at a stated result. Read the exact wording and which kind of subject the page names.
- **Adjustments:** QTAC and the universities list schemes that add to a selection rank or consider disadvantage. Names and rules change; read the page.
- **Traps:** an older Queensland system used a different rank; ignore any old page that uses it and say the page looks out of date. A selection rank is not an ATAR.
