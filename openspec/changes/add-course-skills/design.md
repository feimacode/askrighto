# Design

Unlisted-until-promoted: skills that mention internal-only tools would advertise tools public users cannot call. Implementation: a separate `plugin-internal` entry in the marketplace for testers, and the public entry adds the skills when promotion lands.

The guided-browsing wording is taken from `COURSE_INSTRUCTIONS` via the shared source from `add-host-guidance`, not retyped.

Guardrail wording for international students is reviewed in the legal view before promotion, since it borders on migration advice, which is a regulated activity.
