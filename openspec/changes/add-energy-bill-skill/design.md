# Design

Why a skill and not only tool descriptions: the order of questions, the refusal to assume usage and the honest "not estimated" wording are multi-turn behaviour, which a tool description cannot hold. The skill only sequences and words; every number still comes from tool results.

Worked example uses invented inputs and says so; it must not contain real plan names or prices, which would be unsourced facts.

The `read-your-bill` reference is general guidance on bill layout, not a claim about any retailer's bill. Keep it generic.

Open question: whether to point to the Victorian Default Offer or other regulator pages; only if a tool returns that link with source and date.
