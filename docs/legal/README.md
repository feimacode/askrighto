# Legal view markers

Home loans (credit) need a legal view before any public listing (AGENTS.md rule 5, `docs/home-loans-research.md` section 2). To record one, copy `home-loans-view.template.md` to `home-loans-view.md` in this folder in the promotion pull request. In production the server refuses to start with `home-loans` public unless that file exists with a reviewer, a date and a scope. The file is evidence for people; the check only stops a settings slip.

Do not create `home-loans-view.md` until a person with the right qualification has actually given a view.
